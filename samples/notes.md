# 现场记录（工单 Q-2431）

- 09-22 09:40 值班同学反馈：供应商导出的「物料台账」在自助对账页里整体错位，表头之后每一列都往右挪了一格。
- 09-22 10:05 拿到原始导出（`samples/files/` 里的 04、09 就是当时那两份的脱敏版）。肉眼扫不出问题，逐行数逗号才发现第 3 行
  「名称」列里多了一个引号：`橡皮"擦`。表格软件把它当成没闭合的引号字段，把后面几行全吞进同一格，整份文件就跟着乱了；
  同一批里还有一行是末尾多一个引号（`A-4,...,末尾多一个引号"`），行看着没变，对账时却总是少一条。
- 09-22 10:20 05 号那份是漏了收尾引号，后面两行被吞掉，我们对着屏幕找了半小时才确认不是缺行。
- 09-22 11:00 06 号那份行尾有 CRLF 也有 LF，中间还夹了一个单独的 CR，Windows 上几个软件打开的表现各不相同。
- 09-22 11:30 07、08 两份是 Excel 和记事本「Unicode 文本」另存出来的，开头各带一串编码头字节，其中一份直接打不开。
- 结论：不想再靠表格软件手工打开，需要一个按固定口径解析的工具，把每一条记录和每一处错误（在哪一行、哪一列、为什么）都写成
  能对着原文逐条核对的文本；坏行要么立刻停下，要么跳过继续，但得有上限，别让一份文件刷出十万条错误。
